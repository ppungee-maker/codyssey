# A2-3 실행 가이드

## 1. 설치

```bash
cd missions/A2-3-AI리뷰감정분석대시보드
pip install -r requirements.txt
```

## 2. 전체 파이프라인 실행 순서

```bash
python -m src.main import --file sample_data/reviews_sample.csv   # CSV 리뷰 34건 가져오기
python -m src.main clean                                          # 정제 + 중복제거
python -m src.main analyze --all                                  # AI 감정분석(mock)
python -m src.main extract                                        # 키워드/요약/개선제안
python -m src.main list --sentiment 부정 --sort rating_asc         # 목록 조회
python -m src.main show --id 1                                    # 상세 조회
python -m src.main stats                                          # 통계 요약
python -m src.main dashboard                                      # 차트 3종 + 리포트
python -m src.main export --format csv
python -m src.main export --format jsonl --sentiment 부정
```

## 3. 서브커맨드 옵션

| 서브커맨드 | 옵션 |
|---|---|
| `import` | `--file <경로>` (CSV/Excel) |
| `clean` | (옵션 없음, raw 전체를 멱등하게 재정제) |
| `analyze` | `--all` / `--id N` / `--unanalyzed`(기본값) |
| `extract` | `--sentiment`, `--product`, `--date-from`, `--date-to` |
| `list` | `--sentiment`, `--rating`, `--date-from/to`, `--sort`, `--page` |
| `show` | `--id N` |
| `stats` | (옵션 없음) |
| `dashboard` | (옵션 없음, 차트 3종 + `dashboard_report.md`) |
| `export` | `--format {csv,jsonl,excel}`, `--sentiment`, `--rating-min` |

## 4. 데이터/로그 위치 (모두 gitignore, 실행 시 자동 생성)

- `data/reviews.db` — SQLite (raw_reviews/clean_reviews/sentiments/extracts)
- `output/` — 차트 PNG 3종 + dashboard_report.md + export 파일
- `logs/app.log` — INFO/WARNING/ERROR 로그

`output_example/`에 위 순서로 한 번 실행한 결과가 커밋되어 있다.
`sample_data/reviews_sample.csv`는 34건의 합성 리뷰 데이터(제품 3종 x 긍정/부정/중립
템플릿)로, 요구사항의 "샘플 리뷰 데이터 최소 30건 이상"을 충족한다.

## 5. 실제 LLM으로 감정분석/추출을 교체하려면

`src/ai/mock_provider.py`와 동일한 `SentimentAnalyzer`/`Extractor` 인터페이스
(`src/ai/base.py`)를 구현하는 새 provider를 추가하고, `main.py`에서 import만 바꾸면
된다 — A2-1/A2-2와 동일 패턴.
