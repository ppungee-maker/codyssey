# A2-3 [Project C] AI 기반 고객 리뷰 감정 분석 대시보드 — 모범답안

`AI 활용 학습 (AI Native Advanced)` 과정 미션. CSV/Excel 리뷰 데이터를 가져와 AI로
감정분석·키워드추출한 뒤 대시보드(차트+리포트)를 생성하는 CLI.

## 설계 결정

- **감정분석/키워드추출은 mock**: A2-1/A2-2와 동일한 이유(`docs/repo-conventions.md`
  "코드형 미션" 절) — 실 유료 LLM 키가 없고 `naeto`는 세션 인증이라 제출 코드에 못 쓴다.
  `src/ai/base.py`의 `SentimentAnalyzer`/`Extractor` 인터페이스만 맞추면 실제 API로
  교체 가능하도록 분리했다. mock 구현은 긍정/부정 키워드 사전 기반 스코어링이라
  진짜 NLP 품질은 아니지만, 완벽히 무료·오프라인이고 신뢰도(0.0~1.0)까지 산출한다.
- **샘플 데이터**: `sample_data/reviews_sample.csv`에 제품 3종(무선이어폰/스마트워치/
  블루투스스피커) x 긍정/부정/중립 리뷰 템플릿을 조합해 34건(한국어) + 영문 리뷰 4건 =
  총 38건을 생성(시드 고정, 재현 가능). 요구사항 13(샘플 리뷰 최소 30건)과
  보너스(다국어)를 함께 충족한다.

## 요구사항 충족 매핑

| # | 요구사항 | 구현 |
|---|---|---|
| 1 | argparse 서브커맨드 9종 | `src/main.py::build_parser` |
| 2 | CSV/Excel 수집, 필수/선택 필드, raw 저장 | `src/importer.py` |
| 3 | 정제(필수필드/정규화/별점범위/날짜통일/짧은리뷰필터) + 중복정책 | `src/cleaner.py` + `db.upsert_clean` |
| 4 | AI 감정분석(긍정/부정/중립+신뢰도), 대상옵션, 실패시 스킵 | `cmd_analyze`, `ai/mock_provider.py::MockSentimentAnalyzer` |
| 5 | AI 키워드/요약 추출(2항목 이상) | `ai/mock_provider.py::MockExtractor` (긍정/부정키워드+요약+제안 4항목) |
| 6 | 조회(list/show/stats: 필터/페이지네이션/정렬) | `src/query.py` |
| 7 | 대시보드 시각화 3종 + 한글폰트 | `src/visualize.py` |
| 8 | 리포트(품질지표2+/TOP N/AI결과, 콘솔+파일) | `src/report.py` (`dashboard` 서브커맨드에 통합) |
| 9 | 내보내기(CSV/JSONL/Excel) + 필터 | `src/exporter.py` |
| 10 | config.json + logging | `src/config.py`, `src/logging_setup.py` |
| 11 | 영구 저장소(SQLite) | `src/db.py` (4테이블) |
| 12 | 4개 이상 모듈 분리 | 9개 모듈(config/db/importer/cleaner/query/visualize/report/exporter/logging_setup/main) |
| 13 | 샘플 리뷰 30건+ CSV | `sample_data/reviews_sample.csv` (38건, 한국어 34+영어 4) |

## 보너스 (구현 완료)

| 보너스 요구사항 | 구현 |
|---|---|
| 다국어 감정분석(한국어 외 영어) | `ai/mock_provider.py`에 영문 긍/부정 키워드 사전(`_POSITIVE_WORDS_EN`/`_NEGATIVE_WORDS_EN`) 추가, 대소문자 무관 매칭. 샘플 CSV의 영문 리뷰 4건으로 실제 동작 검증(4건 모두 정확히 분류됨) |
| 감정 변화 알림 | `report.py::check_negative_spike` — 최근 7일 부정비율 vs 이전 30일 비교, 15pt 이상 급증 시 경고. `dashboard` 리포트에 "## 알림" 섹션으로 항상 포함 |
| HTML 대시보드 | `src/html_dashboard.py` — 차트 3개를 base64로 인라인 임베드한 단일 `dashboard.html` 생성(외부 리소스 의존 없음), `dashboard` 서브커맨드 실행 시 자동 생성 |
| 제품/카테고리별 비교 | `compare` 서브커맨드 — `query.compare_products`가 제품별 건수/평균별점/감정비율을 별점 낮은 순으로 반환 |
