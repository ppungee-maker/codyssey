# A2-1 실행 가이드

## 1. 의존성 설치

```bash
cd missions/A2-1-브랜드아이덴티티생성기
python -m venv .venv && source .venv/bin/activate   # 이미 있는 codyssey/.venv 재사용도 가능
pip install -r requirements.txt
```

## 2. 대화형 실행

```bash
python -m src.main
# 브랜드 브리프 JSON 파일 경로를 입력하세요: sample_data/brief_example.json
# 결과를 저장할 폴더 경로 (기본값: ./output): (엔터)
```

## 3. 비대화형(스크립트) 실행

```bash
python -m src.main --brief sample_data/brief_example.json --output output
```

## 4. 실제 OpenAI API로 교체하려면

1. `pip install openai`
2. `.env` 또는 `config.json`에 `OPENAI_API_KEY` 설정
3. `config.json`에 `"provider": "openai"` 지정 (또는 환경변수 `BRAND_PROVIDER=openai`)

키가 없거나 `openai` 패키지가 없으면 자동으로 `mock` provider로 안전하게 대체되고
안내 메시지가 출력된다(요구사항 9).

## 5. 산출물

- `output/brand_result.json` — 네이밍/슬로건/스토리/팔레트/에러 로그
- `output/color_palette.png` — 컬러 팔레트 시각화
- `output/logo_1~3.png` — 로고 시안

`output_example/`에 `sample_data/brief_example.json`으로 미리 한 번 실행한 결과가
커밋되어 있다 — 코드를 직접 돌리지 않아도 산출물 형태를 바로 확인할 수 있다.
