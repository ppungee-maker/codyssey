# A2-1 [Project A] 브랜드 아이덴티티 생성기 — 모범답안

`AI 활용 학습 (AI Native Advanced)` 과정 미션. 브랜드 브리프(JSON)를 입력받아
네이밍/슬로건/스토리/컬러 팔레트/로고 시안을 생성하는 CLI 프로그램.

## 설계 결정: 왜 mock provider가 기본값인가

미션 원문은 "LLM API"/"이미지 생성 API(DALL-E 등)" 호출을 요구하지만, 이 계정엔
실제 유료 API 키가 없다. 세션 쿠키로 인증하는 코디세이 내부 프록시(`naeto`)는 제출
코드에 넣어도 채점자 환경에서 재현 불가능하므로 쓸 수 없다(`docs/naeto-seai-usage.md`).

그래서 `src/providers/base.py`에 `LLMProvider`/`ImageProvider` 인터페이스를 두고,

- `mock_provider.py` — 브리프 내용을 결정적 템플릿에 꽂아 무료·오프라인으로 동작 (기본값)
- `openai_provider.py` — 동일 인터페이스의 실제 OpenAI 구현체 (키 있으면 `config.json`의
  `"provider": "openai"`로 즉시 교체 가능, 키 없으면 자동으로 mock 폴백 + 안내 메시지)

두 구현체 모두 `pipeline.py`에서 완전히 동일하게 호출되므로, 실제 채점 환경에 API 키가
주어지면 코드 수정 없이 진짜 생성형 AI 결과로 바꿀 수 있다.

## 요구사항 충족 매핑

| # | 요구사항 | 구현 위치 |
|---|---|---|
| 1 | 대화형(print/input) 입력, 필수 브리프 경로/선택 출력폴더 | `src/main.py` (`--brief` 인자로 비대화형 실행도 지원) |
| 2 | 브리프 JSON (industry/target/keywords 필수, tone/competitors/notes 선택) | `src/models.py::BrandBrief.from_json` — 필드 검증 + 명확한 에러 메시지 |
| 3 | 브랜드 네이밍 3~5개 + 의미 | `providers/*.generate_naming` → `brand_result.json.namings` |
| 4 | 슬로건 3개 | `providers/*.generate_slogans` |
| 5 | 브랜드 스토리(~300자) | `providers/*.generate_story` |
| 6 | 컬러 팔레트(메인1/서브2~3, HEX) + PNG 시각화 | `providers/*.generate_palette` + `src/palette.py`(matplotlib) → `color_palette.png` |
| 7 | 로고 시안 2~3개 PNG | `providers/*.generate_logos` (mock=PIL 도형+이니셜) → `logo_1~3.png` |
| 8 | 결과 저장(JSON+개별 PNG) | `src/pipeline.py::run` → `brand_result.json` + PNG들 |
| 9 | 에러 처리(단계별 실패해도 계속 진행) | `pipeline.py`의 각 단계가 개별 try/except, 실패는 `errors[]`에 누적 |
| 10 | API 키 코드 미포함, env/설정파일 로드 | `src/config.py::AppConfig.load` (`OPENAI_API_KEY` env 또는 `config.json`) |

## 보너스 (구현 완료)

| 보너스 요구사항 | 구현 |
|---|---|
| 경쟁사 분석 추가 | `providers/*.analyze_competitors` — `brief.competitors` 각각에 대해 분석+차별화 포인트 생성, `brand_result.json.competitor_analysis`에 저장. `competitors`가 비어있으면 스킵 |
| 다국어(영문) 네이밍 | `NamingCandidate.name_en` — mock은 한->영 근사 사전(`_EN_HINTS`) + 로마자 폴백, openai 구현체는 프롬프트에 `name_en` 필드를 함께 요청 |

mock의 영문 네이밍은 진짜 번역이 아니라 사전 기반 근사치다(`mock_provider.py`
상단 주석 참고) — 실제 OpenAI provider로 교체하면 자연스러운 번역이 나온다.
