# 로컬 실행 캡처

Firebase/OpenAI 실제 계정이 없어 배포 전 단계 — 로컬에서 백엔드(uvicorn, mock
provider) + 프론트엔드(정적 서버)를 동시에 띄우고 Playwright로 실제 조작한 캡처.

| 캡처 | 내용 |
|---|---|
| [`01-swagger-ui.png`](01-swagger-ui.png) | `/docs` — 요구사항의 9개 엔드포인트(data 5 + conversations 4 + chat 1)가 전부 등록된 것을 확인 |
| [`02-초기화면.png`](02-초기화면.png) | 프론트엔드 최초 로드 — 데이터 요약(502건, 증가 추세) 정상 표시 |
| [`03-채팅응답.png`](03-채팅응답.png) | "요즘 추세가 어때?" 질문 → 데이터 요약이 시스템 프롬프트에 주입돼 "증가"를 반영한 답변(컨텍스트 주입 실증) |
| [`04-데이터추가.png`](04-데이터추가.png) | 데이터 1건 추가 → 502건→503건, 평균/최고/최저 실시간 재계산 확인(CRUD 동작) |
| [`05-대화불러오기.png`](05-대화불러오기.png) | 새 대화 시작 후 대화 목록에서 이전 대화 클릭 → 해당 대화의 전체 메시지 복원(대화 불러오기 동작) |
| [`06-다크모드.png`](06-다크모드.png) | [보너스] 다크 모드 토글 |

재현 방법은 [`../../docs/00-실행가이드.md`](../../docs/00-실행가이드.md) 참고.
