# M1-2 로컬 실행 가이드

## 1. 백엔드

```bash
cd missions/M1-2-AI비서구축/backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- `http://127.0.0.1:8000/docs` — Swagger UI
- Firebase/OpenAI 키가 없어도 바로 실행된다 — `FIREBASE_CREDENTIALS_JSON`/
  `OPENAI_API_KEY`가 없으면 각각 in-memory store / mock LLM으로 자동 대체된다.
- 서버가 시작되면 `seed_nvda_daily.csv`(M1-1에서 쓴 NVDA 2년치 종가, 502건)를
  자동으로 적재한다 — 별도 명령 없이 바로 데이터 요약/CRUD/챗봇을 시연할 수 있다.

서버를 띄우지 않고 9개 엔드포인트를 한 번에 검증하려면:

```bash
python smoke_test.py   # TestClient로 앱을 직접 구동, CRUD/챗봇/대화기록/에러케이스 전부 확인
```

## 2. 프론트엔드

새 터미널에서:

```bash
cd missions/M1-2-AI비서구축/frontend
python3 -m http.server 5500
```

`http://127.0.0.1:5500/`에서 접속. `config.js`의 `API_BASE_URL`이 백엔드 기본
포트(8000)를 가리키고 있어 별도 설정 없이 바로 연결된다.

## 3. 실제 OpenAI/Firebase로 교체하려면

`backend/.env.example`을 복사해 `.env`(gitignore 처리됨)를 만들고 값을 채운다.

```bash
cp .env.example .env
# .env에 OPENAI_API_KEY, FIREBASE_CREDENTIALS_JSON 등 채우기
uvicorn app.main:app --reload
```

키가 감지되면 `GET /`(health check) 응답의 `ai_provider`/`storage` 값이 자동으로
`openai`/`firestore`로 바뀐다 — 코드 수정 불필요.
