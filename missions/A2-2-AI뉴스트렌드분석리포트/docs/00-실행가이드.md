# A2-2 실행 가이드

## 1. 설치

```bash
cd missions/A2-2-AI뉴스트렌드분석리포트
pip install -r requirements.txt
```

## 2. 전체 파이프라인 실행 순서

```bash
python -m src.main fetch --limit 25       # RSS(BBC Technology) + 크롤링(Hacker News) 수집
python -m src.main clean                  # raw -> clean 정제 + 카테고리 분류
python -m src.main summarize --all        # AI 요약 (mock, 무료)
python -m src.main analyze                # 전체 스코프 종합 인사이트
python -m src.main analyze --category AI  # 카테고리 스코프 분석
python -m src.main report                 # 차트 2종 + 리포트(md) 생성
python -m src.main export --format csv
python -m src.main export --format jsonl --status summarized
python -m src.main export --format excel
```

## 3. 보너스 서브커맨드

```bash
python -m src.main list --category AI --page 1     # 뉴스 목록 조회 (카테고리/키워드/날짜 필터 + 페이지네이션)
python -m src.main show --id 1                     # 뉴스 상세 조회 (요약/감성 포함)
python -m src.main sentiment                        # 뉴스 감성(긍정/부정/중립) 분석 + chart_sentiment.png
```

## 4. 서브커맨드 옵션

| 서브커맨드 | 옵션 |
|---|---|
| `fetch` | `--limit N`, `--method {rss,crawl,both}` |
| `clean` | (옵션 없음, raw 전체를 멱등하게 재정제) |
| `summarize` | `--all` / `--id N` / `--unsummarized`(기본값) |
| `analyze` | `--category <카테고리명>` |
| `report` | `--format {md,txt}` |
| `export` | `--format {csv,jsonl,excel}`, `--status summarized` |
| `list`(보너스) | `--category`, `--keyword`, `--date-from/to`, `--page` |
| `show`(보너스) | `--id N` |
| `sentiment`(보너스) | `--category <카테고리명>`(미지정시 전체) |

## 5. 데이터/로그 위치 (모두 gitignore, 실행 시 자동 생성)

- `data/news.db` — SQLite (raw_news/clean_news/summaries/analyses/sentiments)
- `output/` — 차트 PNG 3종(카테고리분포/일자별추이/감성분포) + report.md + export 파일
- `logs/app.log` — INFO/WARNING/ERROR 로그

`output_example/`에 위 순서로 한 번 실행한 결과가 커밋되어 있다.

## 6. 정기 실행 스케줄링 (보너스)

cron으로 매일 아침 파이프라인을 돌리려면:

```bash
# crontab -e 에 추가 — 매일 09:00에 수집~리포트까지 실행
0 9 * * * cd /path/to/missions/A2-2-AI뉴스트렌드분석리포트 && \
  /path/to/.venv/bin/python -m src.main fetch --limit 25 && \
  /path/to/.venv/bin/python -m src.main clean && \
  /path/to/.venv/bin/python -m src.main summarize --all && \
  /path/to/.venv/bin/python -m src.main analyze && \
  /path/to/.venv/bin/python -m src.main sentiment && \
  /path/to/.venv/bin/python -m src.main report >> logs/cron.log 2>&1
```

각 서브커맨드가 멱등(중복 URL은 `dedup_policy=skip`으로 재수집해도 안전)하므로
매일 실행해도 데이터가 중복되지 않는다.

## 7. 실제 OpenAI 등으로 AI 요약/분석을 교체하려면

`src/ai/mock_provider.py`와 동일한 `Summarizer`/`Analyzer` 인터페이스(`src/ai/base.py`)를
구현하는 새 provider를 추가하고, `main.py`에서 import만 바꾸면 된다 — A2-1의
`providers/openai_provider.py`와 동일한 패턴.
