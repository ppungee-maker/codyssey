# A2-2 실행 가이드

## 1. 설치

```bash
cd missions/A2-2-AI뉴스트렌드분석리포트
pip install -r requirements.txt
```

## 2. 전체 파이프라인 실행 순서

```bash
python -m src.main fetch --limit 25       # RSS(BBC Technology) + 크롤링(Hacker News) 수집
python -m src.main clean                  # raw -> clean 정제 + 카테고리 분류
python -m src.main summarize --all        # AI 요약 (mock, 무료)
python -m src.main analyze                # 전체 스코프 종합 인사이트
python -m src.main analyze --category AI  # 카테고리 스코프 분석
python -m src.main report                 # 차트 2종 + 리포트(md) 생성
python -m src.main export --format csv
python -m src.main export --format jsonl --status summarized
python -m src.main export --format excel
```

## 3. 서브커맨드 옵션

| 서브커맨드 | 옵션 |
|---|---|
| `fetch` | `--limit N`, `--method {rss,crawl,both}` |
| `clean` | (옵션 없음, raw 전체를 멱등하게 재정제) |
| `summarize` | `--all` / `--id N` / `--unsummarized`(기본값) |
| `analyze` | `--category <카테고리명>` |
| `report` | `--format {md,txt}` |
| `export` | `--format {csv,jsonl,excel}`, `--status summarized` |

## 4. 데이터/로그 위치 (모두 gitignore, 실행 시 자동 생성)

- `data/news.db` — SQLite (raw_news/clean_news/summaries/analyses)
- `output/` — 차트 PNG 2종 + report.md + export 파일
- `logs/app.log` — INFO/WARNING/ERROR 로그

`output_example/`에 위 순서로 한 번 실행한 결과가 커밋되어 있다.

## 5. 실제 OpenAI 등으로 AI 요약/분석을 교체하려면

`src/ai/mock_provider.py`와 동일한 `Summarizer`/`Analyzer` 인터페이스(`src/ai/base.py`)를
구현하는 새 provider를 추가하고, `main.py`에서 import만 바꾸면 된다 — A2-1의
`providers/openai_provider.py`와 동일한 패턴.
