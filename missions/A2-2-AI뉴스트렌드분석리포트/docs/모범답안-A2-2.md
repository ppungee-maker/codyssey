# A2-2 [Project B] AI 뉴스 트렌드 및 종합 분석 리포트 — 모범답안

`AI 활용 학습 (AI Native Advanced)` 과정 미션. 뉴스를 자동 수집(RSS+크롤링)하고
AI로 요약·종합 분석한 뒤 시각화 리포트를 생성하는 CLI.

## 설계 결정

- **수집 소스 2종 모두 실제로 동작한다**: RSS는 BBC Technology 피드(`feedparser`),
  크롤링은 Hacker News 프론트페이지(`httpx`+`BeautifulSoup`, 정적 HTML이라 크롤링에
  적합하고 요청량도 1회 GET이라 부담 없음).
- **AI 요약/분석은 mock**: A2-1과 동일한 이유(`docs/repo-conventions.md` "코드형 미션"
  절)로 실제 유료 LLM 키가 없다. `src/ai/base.py`의 `Summarizer`/`Analyzer` 인터페이스만
  맞추면 실제 API 구현체로 즉시 교체 가능하도록 분리했다.
- **카테고리 분류**: `config.py`의 키워드 사전(`AI`/`보안`/`스타트업`/`빅테크`, 매칭 없으면
  `일반`)으로 제목 기반 분류. 실제 LLM 분류로도 같은 자리에서 교체 가능.

## 요구사항 충족 매핑

| # | 요구사항 | 구현 |
|---|---|---|
| 1 | argparse 서브커맨드(fetch/clean/summarize/analyze/report/export) | `src/main.py::build_parser` |
| 2 | 뉴스 수집 2방식(API·RSS + 크롤링), 타임아웃/에러처리, raw 저장 | `collectors/rss_collector.py`, `collectors/crawler.py` → `db.upsert_raw` |
| 3 | 데이터 정제(필수필드/정규화/날짜통일/결측값) + 중복정책 | `src/cleaner.py` + `db.upsert_clean`(skip/upsert) |
| 4 | AI 요약(대상 선택 옵션, 실패시 스킵) | `cmd_summarize` (`--all`/`--id`/`--unsummarized`) |
| 5 | AI 인사이트 분석(트렌드/키워드/공통점차이점/시사점 중 2개 이상) | `ai/mock_provider.py::MockAnalyzer` (4개 항목 모두 포함) |
| 6 | 시각화 2종(카테고리 분포, 일자별 추이), 한글 폰트, PNG | `src/visualize.py` |
| 7 | 리포트(품질지표 2+, TOP N, AI인사이트, 콘솔+파일) | `src/report.py` |
| 8 | 내보내기(CSV/JSONL/Excel 중 2개+, 필터) | `src/exporter.py` |
| 9 | 설정파일(config.json) + logging(INFO/WARNING/ERROR) | `src/config.py`, `src/logging_setup.py` |
| 10 | 영구 저장소(SQLite), 메모리만으로 관리 금지 | `src/db.py` (SQLite 4테이블) |
| 11 | 4개 이상 모듈 분리 | `config/db/cleaner/collectors(2)/ai(2)/visualize/report/exporter/logging_setup/main` = 10개+ |

## 보너스 (미구현 — 확장 지점)

- 데이터 조회 CLI(list/show): `db.fetch_clean`에 페이지네이션/필터 파라미터만 추가하면 됨
- 감성 분석: `ai/` 계층에 `SentimentAnalyzer` 인터페이스 추가로 확장 가능
- 정기 실행 스케줄링: `crontab -e`에 `0 9 * * * cd <repo> && python -m src.main fetch && ... ` 형태로 문서화 예정
