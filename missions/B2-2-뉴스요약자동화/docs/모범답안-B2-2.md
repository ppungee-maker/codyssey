# 모범답안 — B2-2 [Project B] 뉴스 요약 자동화 워크플로우 만들기

이 폴더는 B2-2 미션의 예시답안이다. 미션 원문은 `codyssey mission B2-2`로 확인했다
(전문은 `qa-reports/mission-B2-2-*.md`). 실행 절차는 [`00-실행가이드.md`](00-실행가이드.md),
설계 근거는 [`01-README-기획서.md`](01-README-기획서.md), 프롬프트 검증 상태는
[`02-프롬프트검증.md`](02-프롬프트검증.md) 참고.

**사용 도구**: Make(노코드 자동화), Notion(저장), Claude/OpenAI API(요약 — 프롬프트는
`naeto chat`으로 사전 검증). 이미지 생성 보너스는 네이토(`gpt-image-1-mini`).

> ⚠️ **현재 상태**: `naeto chat` 서버 오류로 요약 프롬프트의 **실제 응답 검증**과
> Make 시나리오의 **실제 구축·실행**(Notion·Make 계정이 필요해 형님 몫)이 아직
> 안 끝났다. 아래 표는 "설계·문서화 완료" 기준으로 체크했고, 실제 동작 확인이
> 필요한 항목은 별도 표시했다.
