# 보너스 — 로컬 대시보드 실행 캡처

`dashboard/index.html`(순수 JS+SVG, 외부 라이브러리 없음, 502건 데이터 embed)을
Playwright로 직접 열고 기간 필터 버튼을 클릭해가며 캡처했다.

## 실행 방법

```bash
python notebooks/build_dashboard.py   # dashboard/index.html 생성
open dashboard/index.html             # 브라우저에서 바로 열림 (배포 불필요)
```

## 필터 시나리오

| 캡처 | 기간 버튼 | 결과 |
|---|---|---|
| [`01-전체기간.png`](01-전체기간.png) | 전체(기본값) | 2024-09-03~2026-09-02, 502건, 구간수익률 +107.8% |
| [`02-1년.png`](02-1년.png) | 1년 | 최근 252거래일만 필터링, 통계가 그 구간 기준으로 재계산됨 |
| [`03-3개월.png`](03-3개월.png) | 3개월 | 최근 63거래일, 구간수익률 +2.6%로 급격히 달라짐(전체기간과 다른 그림) — 짧은 구간일수록 최근 등락에 민감하다는 걸 시각적으로 보여준다 |

버튼 클릭 시 상단 통계 카드(기간/데이터 건수/구간 수익률/최고가/최저가)와 차트가
서버 통신 없이 즉시 재계산된다(embed된 데이터를 클라이언트에서 슬라이싱).
