# M1-1 AI 데이터 분석: 데이터 기반 트렌드 분석 — 모범답안

`AI 응용 학습 (AI Native Master)` 과정 미션. 시계열 데이터를 정제·분석하고
인사이트 리포트를 작성한다.

## 설계 결정

- **실제 공개 데이터를 그대로 사용**: mock/합성 데이터가 아니라 Yahoo Finance 공개
  차트 API에서 NVDA 2년 일봉(502건)을 실제로 수집했다. LLM/이미지 생성 API처럼
  유료 키가 필요한 것도 아니고, 이 미션 자체가 "실제 데이터 해석 능력"을 보는
  미션이라 mock으로 대체할 이유가 없었다.
- **Jupyter 대신 .py 스크립트**: 요구사항은 `.ipynb` 또는 `.py` 둘 다 허용한다.
  이 환경엔 jupyter가 설치돼 있지 않고, `.py` 스크립트가 재현성(그대로 실행하면
  동일 산출물)과 버전관리(diff 가능) 면에서 더 명확해 스크립트로 선택했다.
