# M1-1 실행 가이드

## 1. 설치

```bash
cd missions/M1-1-AI데이터분석시계열트렌드
pip install -r requirements.txt
```

## 2. 재현 순서

```bash
python notebooks/fetch_data.py     # (선택) 데이터 재수집 — data/nvda_2y_daily.csv 갱신
python notebooks/analyze.py        # 정제 + 시계열 분석 + 차트 4개 생성 + 인사이트 콘솔 출력
python notebooks/build_dashboard.py  # [보너스] 인터랙티브 대시보드 생성 (dashboard/index.html)
```

`data/nvda_2y_daily.csv`는 이미 커밋되어 있어 `fetch_data.py`를 다시 실행하지 않아도
`analyze.py`가 바로 동작한다. 재수집하면 "최근 2년" 기준이라 최신 거래일까지 데이터가
갱신되며, `REPORT.md`의 수치는 커밋된 CSV 기준이다.

## 3. 산출물

- `REPORT.md` — 미션이 요구하는 필수 산출물(분석 주제/질문/데이터설명/시각화/인사이트/결론)
- `images/final/01~03_*.png` — 필수 시각화 3종
- `images/final/04_decomposition.png` — [보너스] 추세/계절성 분해
- `dashboard/index.html` — [보너스] 인터랙티브 대시보드 (배포 없이 로컬에서 바로 열림)
- `captures/dashboard/` — 위 대시보드를 Playwright로 조작한 캡처 3장 + 필터 시나리오 설명

## 4. 데이터 출처
