## STEP 1. UI 디자인 이미지 생성 — ✅ 완료

`codyssey naeto image`(네이토 이미지 생성, `gpt-image-1-mini`/`low` 품질)로 화면 3개를
생성했다. 프롬프트 초안→최종 전체 과정은 [`01-작업로그.md`](01-작업로그.md) 참고.

- [x] `images/final/01-메인-여행지검색.png` — 여행지 검색 메인 화면
- [x] `images/final/02-상세-항공권예약.png` — 항공권 예약 상세 화면
- [x] `images/final/03-마이페이지-예약내역.png` — 마이페이지 예약 내역

재현하려면 (직접 화면을 더 만들고 싶을 때):
```bash
source .venv/bin/activate
python3 -c "
from codyssey import naeto
from pathlib import Path
r = naeto.image_gen(
    '<프롬프트>',
    model=naeto.DEFAULT_IMAGE_MODEL,   # gpt-image-1-mini
    size='1024x1536',                   # 9:16 세로
    quality='low',
    out_dir=Path('missions/B2-1-AI기반UIUX디자인시안제작/images/drafts'),
)
print(r.local_paths, r.virtual_tokens)
"
```
⚠️ 저장 폴더가 미리 있어야 이중과금을 피할 수 있다(`image_gen`이 자동으로 `mkdir` 하긴
하지만, `out_dir` 자체를 잘못된 경로로 주지 않도록 주의).

## STEP 2. 텍스트 깨짐 검수 — ✅ 완료

초안 단계에서 검색창 placeholder·좌석선택 라벨·부가정보 문구 등 **작은 다항목 텍스트**가
반복적으로 깨지는 것을 확인했고, 최종본은 그런 텍스트를 아예 프롬프트에서 배제해
전부 해소했다(자세한 비교는 작업로그 참고). 실제 인페인팅 도구로 사후 수정하는 대신
"깨지기 쉬운 텍스트를 요구하지 않는" 프롬프트 설계로 대응 — 이 방침을 모범답안 문서에
명시해둘 것.
