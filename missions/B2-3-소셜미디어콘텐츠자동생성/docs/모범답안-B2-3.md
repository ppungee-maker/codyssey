# 모범답안 — B2-3 [Project C] AI 기반 소셜 미디어 콘텐츠 자동 생성

미션 원문은 `codyssey mission B2-3`로 확인(`qa-reports/mission-B2-3-*.md`). 실행 절차는
[`00-실행가이드.md`](00-실행가이드.md), 프롬프트 설계는 [`01-프롬프트템플릿.md`](01-프롬프트템플릿.md),
프로젝트 개요는 [`02-README.md`](02-README.md) 참고.

**사용 도구**: Make(노코드 자동화), Notion(저장), Claude/OpenAI API(플랫폼별 텍스트),
네이토(`gpt-image-1-mini`, 대표 이미지+보너스 A/B).

> ⚠️ **현재 상태**: `naeto chat` 서버 오류로 플랫폼별 텍스트의 **실제 생성 결과**와
> Make 시나리오의 **실제 구축**(Notion·Make 계정 필요, 형님 몫)이 아직 안 끝났다.
> 이미지 관련 산출물(대표 이미지, 보너스 A/B)은 전부 실제 생성 완료.
