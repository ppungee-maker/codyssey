# README — 프로젝트 개요 / 팀 역할

Notion 페이지 상단에 그대로 붙여넣을 프로젝트 개요 문서(필수 산출물 ② 요구사항).

## 프로젝트 개요

주제 하나를 입력하면 인스타그램·블로그·X(트위터) 3개 플랫폼에 맞는 텍스트와 대표
이미지 1장을 자동 생성해 Notion에 플랫폼별로 저장하는 파이프라인. 샘플 주제:
"친환경 텀블러 신제품 출시".

## 팀 구성원 역할

| 역할 | 담당 | 작업 |
|---|---|---|
| 워크플로우 설계 | 형님 + Claude | 입력 트리거→3플랫폼 분기→이미지 생성→저장 구조 설계 |
| 프롬프트 설계 | Claude | 플랫폼별 톤/포맷 요구사항을 반영한 프롬프트 템플릿 작성 |
| 이미지 생성 | Claude (`naeto image`) | 대표 이미지 1장 + 보너스 A/B 톤 변형 이미지 2장 |
| Make/Notion 구축 | 형님 | 실제 시나리오·데이터베이스 생성 (계정 필요) |

## 개인별 작업 요약

- Claude: 미션 요구사항 분석 → 플랫폼별(인스타/블로그/X) 프롬프트 3종 설계 →
  `naeto image`로 대표 이미지·A/B 톤 변형 이미지 실제 생성 → Make 워크플로우 설계
  문서화. (텍스트 프롬프트의 실제 생성 결과는 `naeto chat` 서버 오류로 대기 중.)
- 형님: Make/Notion 계정 준비 및 실제 시나리오 구축, 실행 캡처.

## 보너스1 — A/B 테스트 결론 (진행 중)

이미지 A/B(친근한 vs 전문적인 스타일)는 생성 완료 — 결과 비교:

| 변수 | A(친근한) | B(전문적인) |
|---|---|---|
| 배경 | 야외, 자연광, 초록빛 | 스튜디오, 어두운 그라디언트 |
| 분위기 | 캐주얼, 따뜻함 | 미니멀, 고급스러움 |
| 어울리는 플랫폼(추정) | 인스타그램(친밀감 중시) | 블로그/제품 상세페이지(신뢰감 중시) |

텍스트 톤 A/B와 종합 결론은 `naeto chat` 복구 후 §5(01-프롬프트템플릿.md)의 텍스트
생성 결과를 반영해 마무리한다.
