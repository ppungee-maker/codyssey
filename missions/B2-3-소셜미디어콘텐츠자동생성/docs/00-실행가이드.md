# B2-3 실행 가이드

> B2-2와 같은 이유로 이 미션도 **실제 Make 워크플로우 + Notion**이 있어야 완성된다 —
> 계정이 필요한 부분은 형님 몫, 정확한 설정값은 여기 다 준비했다.
> 대표 이미지는 `naeto image`로 이미 생성해뒀고(`images/final/`, `images/bonus-ab/`),
> 플랫폼별 텍스트는 `naeto chat`이 서버 오류라 프롬프트 설계까지만 완료 —
> [`01-프롬프트템플릿.md`](01-프롬프트템플릿.md) 참고.

---

## STEP 0. 준비물

- [ ] Make 계정, Notion 계정+워크스페이스
- [ ] Claude 또는 OpenAI API 키 (텍스트 생성용)
- [ ] 이미지 생성 API 키(OpenAI `gpt-image-1` 등) — 또는 `images/`의 naeto 생성 이미지를
  그대로 대표 이미지로 제출해도 무방(사용 도구를 "네이토"로 명시)

## STEP 1. Notion 데이터베이스 만들기

1. [ ] 새 데이터베이스 생성, 이름 예: `소셜 콘텐츠 자동 생성`
2. [ ] 속성:
   | 속성명 | 타입 |
   |---|---|
   | 주제 | Title |
   | 플랫폼 | Select (옵션: 인스타그램/블로그/X) |
   | 콘텐츠 | Text |
   | 이미지 | Files & media |
   | 생성일시 | Created time (자동) |
3. [ ] 페이지 상단에 **프로젝트 개요·팀 구성원 역할·개인별 작업 요약**을 적은 블록 추가
   (미션이 명시적으로 요구하는 항목 — `02-README.md` 내용을 그대로 붙여넣어도 됨).

## STEP 2. Make 시나리오 — 입력 트리거

1. [ ] 새 Scenario, 첫 모듈 → **Webhooks** → **Custom webhook** (주제를 입력받는 폼 역할).
   또는 더 간단하게: **Google Forms** → **Watch Responses**(주제 입력 폼을 Google Forms로
   만들면 UI가 더 쉬움) — 아래는 Webhook 기준으로 서술.
2. [ ] Webhook에 `{"topic": "친환경 텀블러 신제품 출시"}` 같은 JSON을 보내면 트리거되도록 구성.
3. [ ] **Run once**로 테스트 전송 → 페이로드 잡히는지 확인.

## STEP 3. 플랫폼별 텍스트 생성 (3개 분기)

1. [ ] 트리거 뒤에 `Router` 추가, 경로 3개: 인스타그램 / 블로그 / X.
2. [ ] 각 경로에 `HTTP` → **Make a request** (Claude API, B2-2 STEP 4와 동일한 인증 헤더).
   프롬프트만 플랫폼별로 다르게 — 정확한 문구는 [`01-프롬프트템플릿.md`](01-프롬프트템플릿.md).
3. [ ] 세 경로 모두 같은 입력(`{{1.topic}}`)을 받아 병렬로 실행된다(Router는 조건 없이
   전부 통과시키는 "브로드캐스트" 형태로 — 각 경로 필터를 비워두면 3개 다 항상 실행).

## STEP 4. 대표 이미지 생성

1. [ ] Router 앞이나 별도 경로에 `HTTP` → OpenAI `images/generations` 호출 (또는 이미
   생성해둔 `images/final/01-대표이미지-친환경텀블러.png`를 그대로 Notion에 업로드).
2. [ ] 프롬프트: `01-프롬프트템플릿.md`의 이미지 프롬프트 참고.

## STEP 5. Notion 저장 (플랫폼별 구분)

1. [ ] 각 Router 경로 끝에 `Notion` → **Create a Database Item**.
   - 주제: `{{1.topic}}`
   - 플랫폼: 해당 경로 이름(인스타그램/블로그/X)
   - 콘텐츠: 해당 HTTP 응답의 텍스트
   - 이미지: STEP 4에서 만든 이미지(3개 경로 모두 같은 이미지 재사용)
2. [ ] 결과적으로 주제 1건당 Notion 행 3개(플랫폼별)가 생긴다 — "플랫폼별로 구분되어
   저장" 요구사항 충족.

## STEP 6. 보너스 — A/B 테스트

- [ ] 같은 주제로 톤앤매너만 다른 시스템 프롬프트 2벌(친근한 버전 / 전문적인 버전)을
  만들어 STEP 3의 HTTP 모듈을 하나 더 복제해 병렬로 돌린다.
- [ ] 이미지 쪽 A/B는 이미 준비됨: `images/bonus-ab/A-친근한버전.png` vs
  `images/bonus-ab/B-전문적인버전.png`.
- [ ] 결론 정리는 `02-README.md`에 작성.

## STEP 7. 실행 및 캡처

- [ ] Webhook에 실제 주제를 보내 3개 플랫폼 콘텐츠가 Notion에 다 쌓이는지 확인
- [ ] 📸 캡처:
  - [ ] `captures/make/01-전체시나리오.png`
  - [ ] `captures/make/02-실행이력.png`
